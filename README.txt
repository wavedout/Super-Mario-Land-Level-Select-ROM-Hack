Super Mario Land - Level Select

Version 1.1

Small quality-of-life hack that enables Super Mario Land's built-in level select.

- Select any of the game's 12 levels
- Choose Normal or Hard difficulty
- After a game over, the menu remembers the last stage and difficulty
- Updated title menu design

#Controls

On the title screen:

- Up / Down: select START or MODE
- Left / Right on START: select a stage
- Left / Right on MODE: choose NORMAL or HARD
- Start: begin the selected stage and difficulty

After a game over, the menu returns to the stage and difficulty where the player died. The original score-based CONTINUE option is replaced by this retry behavior. Resetting or powering off returns to the defaults.

#Patching

Apply either the .bps or .ips patch to a clean copy of:

Super Mario Land (World)

BPS is recommended. Apply only one patch to the original ROM, rather than patching an older hacked ROM.

Online patcher: https://www.romhacking.net/patch/
